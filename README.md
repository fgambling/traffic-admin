Vue 3 · Vite · Element Plus

---

## 一、环境要求

| 工具 | 版本 |
|------|------|
| Node.js | 18+ |
| npm | 任意 |

---

## 二、配置后端地址

打开 `src/utils/request.js`，将 `baseURL` 改成后端地址：

```js
const http = axios.create({
  baseURL: 'http://localhost:8080',  // 后端不在本机时改成对应 IP
  timeout: 15000
})
```

## 五、功能模块

### 商家管理
查看/编辑商家信息、审批注册（商家需审批通过才能在小程序登录）、启用/禁用账号、查看各商家今日数据快照。

### 业务员管理
查看业务员列表与跟进记录、审批提现申请、设置佣金规则。

### 建议管理
分两个子功能：

**中级版·规则引擎**
- 查看/新增/编辑/删除内置规则（R001–R010）
- 单独控制每条规则的启用/禁用状态（关闭后商家端不再显示该规则生成的建议）

**高级版·AI大模型**
- 选择服务商（OpenAI / 文心一言 / 通义千问 / DeepSeek / MiniMax）
- 填写模型名和 API Key
- 设置每日调用上限（次/商家，0=不限制）
- 自定义 Prompt 模板（支持 `{{data}}` 占位符，点"恢复默认"可重置）
- **必须先点"测试连接"成功，才能保存配置**

### 建议审核
查看所有 AI 大模型生成的建议，可按状态/类型筛选，支持：
- 点击行查看完整内容弹窗
- 标记为优质建议 / 取消
- 隐藏建议 / 取消隐藏

### 费用统计
按商家汇总 AI 大模型的调用次数和预估费用（基于各模型公开定价估算），支持各列排序。

### 系统日志
查看管理员操作记录。

## 六、AI 配置流程（首次使用必做）

1. 进入 **建议管理 → 高级版·AI大模型**
2. 选择服务商，填写模型名和 API Key
3. 点击 **测试连接** → 提示"连接成功"
4. 点击 **保存配置**

> 高级版商家在小程序里手动生成 AI 建议、以及每天凌晨 1 点的定时任务，都依赖此配置。未配置时点击生成会提示错误。

## 七、常见问题

**Q：页面正常但数据加载失败 / 出现 401**
A：检查 `baseURL` 是否指向正在运行的后端，确认后端已启动。

**Q：登录提示密码错误**
A：账号 `admin`，密码 `admin123`，注意区分大小写。

**Q：跨域报错（CORS）**
A：后端已配置跨域，通常是 `baseURL` 填写有误（检查 IP、端口、末尾是否多余斜杠）。

**Q：费用统计显示 ¥0.00**
A：确认当前配置的模型名与系统内置定价表匹配（定价表包含所有支持的模型）；若使用自定义模型名，预估费用为 0 是正常的。
